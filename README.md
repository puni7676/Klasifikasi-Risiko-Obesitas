# analisis-pola-obesitas
Analisis pola kebiasaan hidup dan karakteristik individu pada berbagai kategori status obesitas menggunakan Python.

# FORMAT KETERANGAN
1. Nomor Kelompok: 55
2. Nama Kelompok: kaum deadline
3. Nama Seluruh Anggota Kelompok:
   - Hasan               (123240041)
   - Nurjelita Sukmawati (123240046)
   - Haerunisa           (123240047)
   - Puput Septiani      (123240263)
